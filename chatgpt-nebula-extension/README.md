# 夜航 · ChatGPT 网页皮肤

个人使用的 Chrome 扩展，版本 **0.1.5**。为 `https://chatgpt.com/` 添加蓝色氛围背景、角色壁纸和可调节的半透明面板。设置界面、背景页面与网页适配分别维护，代码有中文注释。

本次将「线框蓝光」的人物切换改为固定 10 秒一轮，在线框和有色人物画面间叠化。新开关默认关闭，升级保留已有静态线框外观；启用方法见下文。两张图片是本项目生成的原创素材，切换发生在独立背景中。源码工程中的实现范围见 `../docs/人物双态背景说明-0.1.5.md`。

0.1.3 修好的输入区圆角表面、正文居中、右侧面板分配和用户底栏实底继续保留。修订历史见项目根目录 `CHANGELOG.md`。网页节点和变量仍不是稳定的官方皮肤接口，需在当前账号页面核对效果。

## 在 Chrome 中加载

1. 压缩包使用前先解压。打开 Chrome，在地址栏输入 `chrome://extensions`。
2. 打开右上角的「开发者模式」，点击「加载已解压的扩展程序」。
3. 选择**直接包含 `manifest.json` 的文件夹**。本项目中是 `chatgpt-nebula-extension`。
4. 打开或刷新 `https://chatgpt.com/`。点击浏览器扩展按钮中的「夜航」，可将它固定到工具栏。
5. 点击「壁纸与更多设置」。要接近原 DSH 动图，点击「应用原版风格 · 线框蓝光」。普通的背景预设按钮只换背景；一键按钮同时调整面板、颜色、压暗、焦点、扫描纹理，并开启「人物画面切换」。它保留你的启停、动态开关及已保存素材。升级不会自动改写当前外观。
6. 要播放人物切换，确保「启用皮肤」「动态效果」和「人物画面切换」均已开启，背景为「线框蓝光」。如果保留当前配色，只选择该预设并打开两个动态开关即可。系统选择减少动态效果时，仍显示静态线框。

扩展程序加载页由 Chrome 提供，这是未上架的本机扩展加载方式。[Chrome 官方加载说明](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world)

## 能调什么

- **启用皮肤**：开关后立即应用到已打开的匹配网页；关闭时移除背景及自身样式属性。
- **轻量 / 通透**：轻量改变基础配色和有限透明效果；通透额外清理可识别正文表面的实色背景。
- **五个预设**：极光、深海、暮纸、星夜角色、线框蓝光。角色壁纸随包提供，没有远程图片依赖。
- **本机素材**：PNG、JPEG、WebP、GIF、MP4、WebM，单个文件最多 50 MiB。实际能否解码还取决于浏览器对文件编码的支持。
- **画面调节**：背景压暗、横纵焦点、面板不透明度、输入表面模糊、强调色、扫描线和动态开关。用户底栏保持实底，侧栏及顶部布局外壳保留原生定位关系。
- **动态控制**：线框预设具有缓慢蓝光和稀疏代码雨；新增「人物画面切换」独立开关，默认关闭。开启后用两张原创静态图进行 10 秒周期的叠化。视频静音循环。关闭动态时暂停光效和视频，GIF 改用静态封面，人物回到线框；系统减少动态时保持静态。网页不可见时暂停自身动画，回到前台后继续。

自定义素材成功解码并生成封面后才替换旧记录。素材会在本扩展的本机存储中保留，恢复默认设置保留它；「清除本机素材」会先显示确切文件名，再要求确认。清除只影响扩展保存的副本。若多个设置页同时更换素材，旧的清除确认不能删除新素材。

默认压暗 35%、面板不透明度 82%、模糊 8 px。正文不够清晰时，提高压暗和面板不透明度；机器负载较高时，关闭动态、降低模糊或换静态图片。

「应用原版风格」使用通透模式、压暗 18%、面板不透明度 48%、模糊 8 px、强调色 `#52DEFF`、扫描纹理和人物切换。输入表面不透明度最低为 65%，保证输入可读；账户底栏始终实底。人物切换是缓慢叠化，不含真实变形、Live2D、回复触发动作或原 GIF 的逐帧动画。这里不显示 DSH 的模型额度、余额或计费数据。

人物切换使用随包提供的第二张 PNG，开启功能后按需读取并解码。若有色图不能解码或两图尺寸不一致，会保留线框并显示背景状态提示；线框底图本身失败则回退到极光。切换预设或本机素材后会解除人物叠层。关闭「人物画面切换」可以继续使用线框、蓝光和代码雨。

## 数据和权限

运行时只请求 `storage`，内容脚本只匹配 `https://chatgpt.com/*`；不读取会话内容、Cookie 或账户信息，不发起模型请求，也没有云同步、远程脚本和远程素材源。背景 iframe 不接收鼠标点击，不进入键盘焦点。

设置保存在 `chrome.storage.local`；媒体 Blob 保存在扩展源的 IndexedDB，由独立背景页面读取。扩展网页与内容脚本的存储差异、嵌入扩展页面的存储分区规则见 [Chrome 存储文档](https://developer.chrome.com/docs/extensions/develop/concepts/storage-and-cookies)。本扩展声明最低 Chrome 115，**实际测试的版本请看项目验证记录**；最低声明不能代替逐版本兼容性测试。

只有 `backdrop.html` 向指定的 ChatGPT 源开放，其他资源在扩展页面内部使用。该资源声明的含义见 [Chrome 网页可访问资源文档](https://developer.chrome.com/docs/extensions/reference/manifest/web-accessible-resources)。

## 关闭、更新与排查

临时关闭：点击夜航弹窗，关闭「启用皮肤」。如果扩展刚重载而旧网页尚未刷新，请刷新该网页以重新连接扩展。

代码更新：保留现有加载目录，把新的运行文件放在原位置，然后在 `chrome://extensions` 中点击本扩展的刷新按钮，最后整页刷新 ChatGPT。沿用原目录和扩展标识可继续使用现有配置与本机素材；换目录可能改变标识，设置与素材不一定沿用。更新后可在扩展页确认版本为 **0.1.5**。本次新增的人物切换默认关闭，不会自动覆盖旧外观。首次使用前无需安装任何开发依赖。

出现问题时，按顺序尝试：

1. 关闭皮肤确认原网页可以使用，再开启并选「轻量」。
2. 选择「极光」预设并关闭动态，排除自定义素材问题。
3. 打开完整设置，查看背景状态与素材提示；预览成功只说明背景渲染成功。
4. 如果只有网页局部仍是不透明或颜色不对，记录该位置和截图，检查 `styles/site.css` 中对应适配规则。
5. 如果 Chrome 的扩展加载页显示错误，查看错误详情。修改后重载扩展、刷新网页。

## 维护入口

| 文件 | 职责 | 网页改版时的关系 |
| --- | --- | --- |
| `styles/site.css` | 基础颜色、侧栏、输入框、正文透明效果、弹层保护 | 首先检查这里的变量与语义选择器 |
| `content.js` | 挂载/清理背景，监听顶层替换，接收设置变更 | 背景不出现或被移除时检查 |
| `backdrop.*` | 独立背景、媒体播放、静态封面、回退、资源释放 | 通常不依赖 ChatGPT 内部结构 |
| `shared/settings.js` | 规范化配置、跨页保存锁、默认值 | 设置失效时检查 |
| `shared/media-store.js` | 解码、封面、IndexedDB、素材版本核对 | 本机素材问题时检查 |
| `options.*` / `popup.*` | 完整设置 / 快捷开关 | 自己的界面，可独立修改 |
| `manifest.json` | 匹配范围、入口、权限、内容安全策略 | JSON 不允许注释，字段说明见维护文档 |

项目没有构建步骤。完整源码工程中的测试与维护说明在项目外层 `docs/维护与验证说明.md`；本次验证记录为 `docs/验证记录-0.1.5.md`，本次分享目录收录当前版本资料，历史修订见 `CHANGELOG.md`，浏览器回归脚本在源目录的 `tests/`。发布压缩包仅包含运行文件和本安装说明，不包含外层文档、测试代码或测试浏览器资料；这些材料保留在源码工程中。

## 验证范围

交付前使用真实 Chrome 扩展环境在本机离线网页夹具上测试。原有夹具具有常见 ChatGPT 语义节点和严格网页内容安全策略，用于验证扩展机制、素材、交互和清理；新增 Work 夹具根据公开源码中的语义节点、颜色变量及 CSS 分层规则构造，用于对照修复前后的侧栏与输入区效果。它不是用户实际网页导出的 DOM。**这些检查不能证明当前登录账号的真实 ChatGPT 网页已全面兼容**；该项需要在用户加载后的页面确认。静态效果设计图也不是实际网页截图。

网页结构、样式变量或浏览器行为改动仍可能需要修补。用户已经接受长期维护，本项目将可变的网页样式依赖集中处理；不承诺未来改版自动兼容。
