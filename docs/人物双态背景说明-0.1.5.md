# 人物双态背景说明 · 0.1.5

日期：2026-10-07。本轮继续靠近用户上传的 DSH 动图：在已接受的线框蓝光背景上增加有色人物画面，并按 10 秒周期缓慢叠化。原有输入框、正文居中、右侧资料面板与账户底栏样式沿用 0.1.3。

## 如何开启

先在 Chrome 扩展页重载夜航，再整页刷新 ChatGPT，确认版本为 **0.1.5**。打开「壁纸与更多设置」，有两种方式：

1. 保留当前面板参数：选择「线框蓝光」，打开「动态效果」和「人物画面切换」。
2. 使用整套参考风格：点击「应用原版风格 · 线框蓝光」。按钮同时应用通透、青蓝色、压暗、焦点、扫描纹理，并开启人物切换；已有「启用皮肤」与「动态效果」状态会保留。如果总动态原来关闭，需要自行打开才会播放。

新增的「人物画面切换」默认关闭，所以只升级不会改变你原来的静态线框选择。普通预设按钮只换背景，也不会自动打开这个新开关。设置与本机素材仍保存在原扩展中。

## 画面与开关行为

线框底图保持在下层，有色人物在其上缓慢出现、停留、再退去。一个周期 10 秒：0–2 秒保留线框，2–4 秒逐渐转为人物，4–6 秒保留人物，6–8 秒回到线框，8–10 秒保持线框，再进入下一轮。原有缓慢蓝光、稀疏代码雨和可选扫描纹理继续使用。

| 操作或条件 | 人物画面 |
| --- | --- |
| 开启皮肤、线框预设、总动态与人物切换，系统未减少动态 | 两图解码成功且尺寸一致后，开始叠化 |
| 只关闭人物切换 | 回到静态线框；总动态开启时，蓝光与代码雨继续 |
| 关闭总动态或系统启用减少动态 | 人物回到线框，装饰停止自身动画 |
| 网页不可见 | 暂停当前动画相位，回到前台后继续 |
| 换为其他预设或本机素材 | 解除人物叠层，使用所选背景 |
| 有色图失败或尺寸不一致 | 保留线框，背景状态提示人物切换未能启用 |
| 线框底图失败 | 按原流程回退到极光 |
| 关闭皮肤 | 移除扩展自己的背景层 |

新有色图仅在需要播放时按需读取，不随每次循环更换图像地址。关闭人物切换会退出该项的失败状态，重新打开后可再试。切换素材、退出页面和恢复流程都清理旧叠层，防止过期解码结果重新显示旧人物。

## 与参考的关系

用户原 GIF 经读取为 1920×1078、78 帧，总时长约 5.87 秒；已检查第 0、39、77 帧。第 0 帧主要是线框与横向光束，第 39 帧出现有色人物。该观察来自上传文件，不代表已掌握 DSH 的内部实现。

本版采用两张 **1672×941** 的原创静态图，通过透明度过渡接近“线框 → 人物 → 线框”的视觉变化。10 秒节奏是本项目的设计选择，较原 GIF 更缓慢。它不包含真实的网格变形、骨骼动画、Live2D、人物表情驱动或回复触发动作，也不是原 GIF 的逐帧复刻。两图同尺寸不等于像素级对应；生成图之间仍可能存在细节差异。

原图中的 DSH 品牌、会话列表、额度、余额和计费没有画进新素材，也没有作为 ChatGPT 信息显示。完整生成提示词、实际尺寸与输出路径见 [人物双态素材生成记录](人物双态素材生成记录-0.1.4.md)。
