# GitHub 材料整理说明

本目录是 0.1.5 的独立分享副本。收录当前可加载插件、六类测试及匿名夹具、当前实际采用的验证报告、维护和规划文档、素材完整提示词、必要效果图，以及当前运行包和 0.1.4 对照包。代码保留中文注释。

原工程中的文件与旧版本均保留。本次没有执行 Git 初始化、提交、推送或 GitHub 上传。

## 副本处理

- 插件的 21 个运行文件原样复制，与 0.1.5 运行 ZIP 一致。
- 测试脚本通过项目依赖或环境变量读取 Playwright，去掉个人电脑的依赖路径。Work 模拟夹具使用“示例用户”。
- 分享报告归一化本机项目、用户目录等路径；测量值、断言、版本、时间戳和运行文件哈希保留，并在报告中注明副本处理。
- 素材记录保留生成方式、实际尺寸与完整提示词，省略个人电脑的原始生成输出路径。历史素材记录中的 20 秒指生成当时的 0.1.4 用法；当前周期为固定 10 秒，见本版背景说明。
- 运行截图中的导航和用户信息为模拟数据。原始参考 GIF 界面抽样、个人浏览器资料、签名私钥、临时测试 run、重复失败诊断及其他项目文件未复制。

## 文件与版本

`docs/整理清单.json` 列出分享文件的相对路径、大小和 SHA-256，清单自身不纳入自引用哈希。`releases/夜航-Chrome-0.1.5.zip` 是当前运行包；0.1.4 包只用于版本对照。

源码的最低 Chrome 声明不能代替逐版本测试。最新运行与实测限制见 [0.1.5 验证记录](验证记录-0.1.5.md)。此前的完整失败过程和历史浏览器资料留在原工程，分享目录以当前可用材料为主，旧修订概要见根目录 [CHANGELOG.md](../CHANGELOG.md)。
